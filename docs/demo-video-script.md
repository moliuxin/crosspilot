# 90 秒演示视频脚本

**0–8 秒｜问题**
画面：传统建站后台菜单密密麻麻。
旁白：外贸企业真正缺的不是“更多建站功能”，而是更快上线、更容易被找到、更多有效询盘。

**8–22 秒｜AI 建站入口**
画面：输入企业信息 → 生成首页 → 1 秒品牌动效 → 成品网站。
旁白：WorkBuddy SitePilot 根据企业、产品和目标市场，生成可直接使用的 B2B 独立站。

**22–38 秒｜商家后台**
画面：5 个一级入口依次亮起。
旁白：后台只保留五件事：网站、产品、页面、询盘和 AI 增长。复杂技术配置全部隐藏。

**38–54 秒｜三语言不同页面**
画面：EN → RU → 中文切换，Hero 文案和策略同步变化。
旁白：多语言不是翻译。每个市场都有自己的信息密度、信任元素、图片风格和转化方式。

**54–72 秒｜核心收费能力**
画面：单产品 SEO 页面从 58 → 91，显示 URL / FAQ / Schema Diff。
旁白：SitePilot 会告诉客户“为什么这个页面搜不到”，并展示优化前后的具体差异。确认后，一键进入专业优化服务。

**72–84 秒｜Agent + MCP**
画面：AI Agent 查询“找出英文站 SEO 不完整的 10 个产品”。
旁白：未来通过 MCP，Agent 能直接读取产品、页面、询盘和搜索数据，生成修改草稿并等待人工确认发布。

**84–90 秒｜结尾**
画面：平台 + 网站双屏。
旁白：WorkBuddy SitePilot —— 不只是建一个站，而是让独立站持续产生增长。
