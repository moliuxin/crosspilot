# WorkBuddy SitePilot 产品方案（Demo 版）

## 1. 产品定位

SitePilot 不是“低价 AI 网页生成器”，而是面向 B2B / 外贸企业的 **AI 独立站智能体 + 专业增长服务平台**。

免费建站是获客入口；持续收费来自页面迭代、多市场本地化、SEO、GEO、专业优化和线索运营。

## 2. 三层产品结构

### A. 访客网站
- 首页
- 产品列表 / 详情
- 解决方案
- 案例
- 企业实力
- FAQ
- RFQ / 询盘

### B. 商家后台
只展示商家能理解的业务动作：
- 我的网站
- 产品中心
- 页面内容
- 询盘中心
- AI 增长

### C. 平台专业后台
隐藏技术项：
- Title / Meta / H1-H6
- Slug / Canonical / Sitemap / robots
- Schema
- Internal Link
- ALT
- llms / Entity Graph
- 多市场模板规则
- 页面质量与版本审核

## 3. 免费转付费

1. 用户输入行业 / 企业名称，先看到首屏预览。
2. 继续生成完整网站时进行企业身份核验。
3. 每家企业免费完整生成 1 次，可允许 1 次小改。
4. 发布、独立域名、继续生成、高级 Skill、SEO/GEO、专业代优化需付费。
5. 免费结果始终保留“效果展示”，让用户先理解价值再付费。

## 4. 核心收费 Skill

- Product SEO Optimizer：按页面收费
- AI Search Visibility / GEO：订阅 / 专业服务
- Market Localization：按市场或语言收费
- Competitor Intelligence：按次或套餐
- Product Copy Agent：Credits
- Visual Scene Generator：Credits
- Redesign Agent：按站收费

## 5. 多语言原则

Language ≠ Translation

Language = Market Template

同一产品数据，按市场变化：信息密度、Hero、CTA、案例、资质、联系方式、图片风格与采购内容顺序。
